# Publishing Guide

## Overview

Publishing makes your **Course** or **Learning Universe** visible to students. Draft content stays private to instructors and admins.

## Learning Universe publish checklist

1. **Title and description** filled in branding setup.
2. At least one **track** with a **lesson**.
3. All required steps have content (no empty quizzes or labs).
4. **Pricing** set (free or premium) if selling.
5. **Thumbnail / banner** uploaded (recommended).
6. Click **Publish** from the studio or course management page.

## Cannot publish — common causes

| Issue | Fix |
|-------|-----|
| Missing title | Course branding setup |
| No lessons | Add content in Visual or Academic Studio |
| Validation errors | Open compile/preview panel and fix errors |
| Draft only | Click **Publish** not just Save |
| Permission denied | Confirm instructor role is approved |
| Payment not configured | Admin must enable payments for paid courses |

## Traditional course publish

1. **Instructor → My Courses → Edit course**.
2. Complete curriculum (sections, lectures, videos).
3. Set price and category.
4. Submit for review if admin approval is required.
5. Status changes to **Published** when approved.

## After publishing

- Students find courses via **Browse**, category hubs, or direct links.
- Updates to content may require re-publish or save depending on the editor.
- Unpublish or archive from course settings (instructor/admin).

## Student visibility

Published courses appear in search and browse. Unpublished drafts return 404 or "not available" for students.
