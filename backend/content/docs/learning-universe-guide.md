# Learning Universe Guide

## What is a Learning Universe?

A **Learning Universe** is THE GATEHUB's structured learning product: tracks, modules, lessons, quizzes, coding labs, research papers, and projects. It is different from a legacy **Course** (video + sections model).

| Feature | Learning Universe | Traditional Course |
|---------|-------------------|-------------------|
| Structure | Tracks → Modules → Lessons → Steps | Sections → Lectures |
| Authoring | Visual Studio or Academic Studio | Curriculum builder |
| Labs | Coding Lab, Notebook, Research | Optional resources |
| Progress | Per-step checkpoints | Lecture completion |

## Student: Enroll and learn

1. Browse or open a Learning Universe from **Dashboard → My Courses** or the public course page.
2. Click **Enroll** (free or paid).
3. Open **Continue Learning** to enter the player.
4. Use the **course outline** sidebar to switch lessons.
5. Complete steps: read content, take quizzes, open labs, submit projects.
6. Earn a **certificate** when all requirements are met.

## Instructor: Create a Learning Universe

1. Go to **Instructor Dashboard → Create Course** or **Learning Universe → New**.
2. Choose **Visual Authoring Studio** (block-based) or **Academic Authoring Studio** (LaTeX DSL).
3. Add tracks, modules, and lessons.
4. Add components: overview, objectives, quiz, coding lab, research paper, project.
5. **Preview** as a student from the instructor menu.
6. **Publish** when content and branding are complete.

## Checkpoints and progress

- **Checkpoints** gate progression (quiz pass, lab submit, project approval).
- Students see **course progress** in the lesson header.
- Instructors review **project submissions** under **Project Reviews**.

## Publishing

Before publish, ensure: title, description, branding, at least one lesson, and pricing (if premium). Draft universes are visible only to instructors until published.

## Navigation paths

- Instructor list: `/instructor/courses`
- Visual studio: `/instructor/learning-universe/new/visual`
- Academic studio: `/instructor/learning-universe/new/academic`
- Student player: `/learning-universe/{id}/learn`
