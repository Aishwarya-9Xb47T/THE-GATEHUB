# Troubleshooting

## Login Issues

- Clear browser cache and cookies.
- Use **Forgot Password** to reset.
- Ensure you are on the correct role (student vs instructor URL).

## Video Playback

- Disable ad blockers for embedded YouTube/Vimeo.
- For uploaded videos, confirm enrollment is active.

## Practice / Code Blocks

- Match the language selector to your code.
- Python and JavaScript run server-side; HTML/CSS may preview in-browser.

## Publish Failures

- **Colab URL invalid** — use a full `colab.research.google.com` notebook URL.
- **Asset not found** — upload images/videos before publishing in Visual Studio.

## PDF / Notes

- If PDF fails to load, try downloading instead of inline view.
- Large PDFs may take time on slow connections.

## Contact Support

Use the **THE GATEHUB Assistant** (bottom-right) for documentation-based answers.
