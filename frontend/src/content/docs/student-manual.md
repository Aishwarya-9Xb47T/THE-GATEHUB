# Student Manual

## Welcome

THE GATEHUB provides courses, Learning Universes, interactive practice, quizzes, projects, and certificates. This manual covers everything you need as a student.

## Dashboard

Your dashboard shows enrolled courses, Learning Universes, recent activity, and certificate progress. Use the sidebar to navigate:

- **My Courses** — traditional video + notes courses
- **Browse** — discover new content
- **Certificates** — earned and in-progress certificates
- **Quiz Results** — history of quiz attempts

## Courses

### Enrolling

1. Open a course from Browse or the landing page.
2. Click **Enroll** (free) or **Buy Now** (paid).
3. After payment, access opens immediately.

### Learning

- Watch lecture videos in the course player.
- Read compiled notes (PDF) alongside videos.
- Complete section quizzes when available.

## Learning Universes

Learning Universes are structured paths: **Tracks → Modules → Lessons → Content Blocks**.

### Navigating

1. Open a Learning Universe from Browse or your enrollments.
2. Use the lesson sidebar to move between lessons.
3. Content blocks render in order: theory, videos, practice, quizzes, projects.

### Progress

Progress is saved automatically: lessons completed, videos watched, practice passed, quizzes passed, projects submitted.

## Watching Videos

- YouTube and Vimeo embeds play in-page.
- Uploaded videos stream from THE GATEHUB CDN.
- Video watch progress counts toward lesson completion.

## Viewing Notes

- Lecture notes may appear as PDF or rich content blocks.
- Use fullscreen on PDFs for better reading.

## Try It Yourself

Practice blocks include a code editor (Monaco), **Run**, **Reset**, **Show Solution**, and **Show Hint**.

Supported languages include Python, JavaScript, HTML, CSS, SQL, Java, C, C++, C#, and Go.

Your output is compared to the expected output for pass/fail.

## Quizzes

- Single choice, multiple choice, and other question types may appear.
- Submit answers to see explanations.
- Passing all quizzes may be required for certificates.

## Assignments

Assignments show due dates, points, and instructions. Submit through the assignment interface when available.

## Projects

### General Projects

Open the project workspace from the lesson. Submit via:

- GitHub repository URL
- Google Colab notebook link
- ZIP upload
- PDF report
- Text submission

### Google Colab Projects

1. Click **Launch Notebook** if a Colab URL is provided.
2. Complete the notebook.
3. Submit your Colab link or upload the `.ipynb` file.

### GitHub Projects

1. Create a repository per instructions.
2. Submit the repository URL in the project workspace.
3. Wait for instructor review.

## Certificates

### Earning Certificates

Certificate rules vary per course. Common requirements:

- Complete all lessons
- Pass all quizzes
- Submit and pass all projects
- Achieve minimum score (e.g. 70%)

### Downloading Certificates

Go to **Certificates** in the sidebar. Click **Download PDF** on earned certificates.

## Progress Tracking

THE GATEHUB tracks:

- Lesson completion
- Video watched percentage
- Practice block completion
- Quiz pass status
- Project submission and approval
- Final exam pass (if applicable)

Resume from your last lesson automatically.

## Reviews

Leave course reviews after enrollment. Ratings help other students and instructors.

## Troubleshooting

### Video won't play

- Check your internet connection.
- Try another browser (Chrome recommended).
- For uploaded videos, ensure you are enrolled.

### Practice code won't run

- Verify language selection matches your code.
- Check for syntax errors in the output panel.

### Certificate not issued

- Confirm all completion rules are met.
- Contact your instructor if requirements are complete but certificate is missing.
