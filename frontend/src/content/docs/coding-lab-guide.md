# Coding Lab Guide

## Overview

**Coding Labs** are interactive programming steps inside a Learning Universe lesson. They support in-browser exercises and **Google Colab** notebooks.

## Student workflow

1. Open the lesson from **My Courses → Continue Learning**.
2. Select the **Coding Lab** step in the lesson outline.
3. Read instructions in the workspace panel.
4. **Run code** in the embedded editor or click **Open in Google Colab**.
5. Click **Submit** when your solution passes tests (if autograding is enabled).
6. Use **Previous / Next** to move between lesson steps.

## Run code in the browser

Some labs use THE GATEHUB's built-in code runner. Click **Run**, view output in the console panel, and fix errors shown in red.

## Connect Google Colab

1. Click **Connect Colab** or **Open in Google Colab**.
2. Authorize Google on first use (**Settings → Integrations**).
3. Complete the notebook; return to THE GATEHUB to submit.

## Common issues

### Code does not run

- Check language matches the lab (usually Python).
- Ensure inputs are valid and required packages are allowed.

### Submit button disabled

- Run all required cells in Colab.
- Pass hidden tests if the lab uses autograding.
- Confirm you are enrolled in the universe.

### Cannot find Coding Lab

Coding Labs appear only on the lesson step labeled **Coding Lab**. Open the course outline and select that step.

## Instructor: Author a coding lab

1. Visual Studio → add **Coding Lab** block to a lesson.
2. Set starter code, instructions, and optional Colab URL.
3. Configure test cases if supported.
4. Preview and publish.
